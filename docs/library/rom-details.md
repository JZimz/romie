# ROM Details

Click any game in your library to open its detail view.

## What you'll see

**Title**: the matched game name from RetroAchievements, or the filename if there's no match.

**System**: the console this game is for.

**Tags**: the tags currently applied to this game. You can add or remove tags right here.

**Favorites**: star a game to add it to your Favorites list in the sidebar.

**Achievement info**: if you're connected to RetroAchievements and the game has achievements, you'll see the total achievement count and your current progress. See [RetroAchievements](/retroachievements/overview) for how to set that up.

## Editing a game

You can update the display name of any game if the auto-detected name isn't right. Just click the name and edit it.

## Removing a game

Hit **Remove** to delete the game from ROMie. This only removes it from your library. The actual ROM file on disk is not touched.
