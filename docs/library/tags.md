# Tags

Tags are the main way you organize what gets synced to your device. Think of them as playlists, you can create as many as you want and a game can have multiple tags.

## Creating a tag

Open any game and click the tag field. Type a new tag name and hit enter. That tag is now created and applied to the game. From there it'll show up in your sidebar under **Tags**.

## Adding tags to games

Open a game and click the tag field. You'll see your existing tags, select any to apply them, or type a new one to create it on the spot.

## Using tags for sync

When you sync to a device, you pick which tags to include. Only games with those tags get copied. This is how you build a curated set for your device, you don't have to sync your whole library every time.

Common patterns people use:

- A tag per device, "MiyooMini", "RG35XX"
- A tag for portable-friendly games, "Short Sessions", "Handheld Good"
- Curated lists, "All-Time Faves", "Currently Playing"

## Removing a tag

To remove a tag from a game, open the game and click the X next to the tag name. If you remove a tag from all games it disappears from the sidebar automatically.
