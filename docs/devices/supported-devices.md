# Supported Devices

ROMie uses firmware profiles to know where to put files on your SD card. Here are the built-in profiles and what they support.

## Onion OS

For **MiyooMini** and **MiyooMini+** devices running [Onion OS](https://github.com/OnionUI/Onion).

Supported systems: NES, SNES, Game Boy, Game Boy Color, Game Boy Advance, Nintendo DS, Sega Genesis/Mega Drive, Sega Master System, Game Gear, PlayStation, Atari 2600, Atari Lynx, Neo Geo Pocket, Virtual Boy, PC Engine, MSX, WonderSwan, Arcade (FBNeo)

## muOS

For **RG35XX**, **RG35XX+**, **RG35XX-H**, and other Anbernic devices running [muOS](https://muos.dev).

Supported systems: NES, SNES, Nintendo 64, Game Boy, Game Boy Color, Game Boy Advance, Nintendo DS, Sega Genesis/Mega Drive, Sega Master System, Game Gear, PlayStation, Atari 2600, Atari Lynx, Neo Geo Pocket, Virtual Boy, PC Engine, MSX, WonderSwan, Arcade

## Knulli

For a range of Anbernic and other ARM handhelds running [Knulli](https://knulli.org).

Supported systems: NES, SNES, Nintendo 64, Game Boy, Game Boy Color, Game Boy Advance, Nintendo DS, Sega Genesis/Mega Drive, Sega Master System, Game Gear, PlayStation, Atari 2600, Atari Lynx, Neo Geo Pocket, Virtual Boy, PC Engine, MSX, WonderSwan, Arcade (FBNeo)

## RetroArch (Generic)

A general-purpose profile for any device running RetroArch with a standard folder layout. Good fallback if your device isn't listed here.

## Custom profiles

Don't see your device? You can create a custom profile with whatever folder structure your firmware uses. Go to **Devices → Add Device**, select **Custom** as the profile type, and define the system mappings manually.

If you've built a profile for a popular device that isn't listed here, consider contributing it back, open an issue or PR on [GitHub](https://github.com/JZimz/romie).
