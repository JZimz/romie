# RetroAchievements Setup

## Get your API key

1. Log in to [retroachievements.org](https://retroachievements.org)
2. Go to your [control panel](https://retroachievements.org/controlpanel.php)
3. Find the **Authentication** section
4. Click the copy icon next to your **Web API Key**

If you don't have a RetroAchievements account, you can [create one for free](https://retroachievements.org/createaccount.php).

## Connect in ROMie

1. Open **Settings** in ROMie
2. Go to the **RetroAchievements** section
3. Enter your username and paste your API key
4. Click **Save**

ROMie will verify the credentials and show your profile if everything checks out.

## What happens after connecting

Once connected, opening any game in your library will show its achievement stats, how many achievements exist and how many you've earned. This data is fetched live from RetroAchievements, so it always reflects your current progress.

## Disconnecting

To remove your RetroAchievements account from ROMie, go to **Settings → RetroAchievements** and click **Remove**. Your API key is deleted from secure storage and ROMie stops making requests to the API. Your library and ROM files are not affected.
