# Installation

ROMie runs on macOS and Windows. Download the latest release from the [GitHub releases page](https://github.com/JZimz/romie/releases) and grab the right file for your system.

**macOS**: download the `.dmg` file, open it, and drag ROMie to your Applications folder.

**Windows**: download the `.exe` installer and run it.

That's it. No setup wizard, no account required.

## First Launch

When you open ROMie for the first time you'll have an empty library. Head over to [Importing ROMs](/getting-started/importing-roms) to get your games in, or jump straight to the [Quick Start](/getting-started/quick-start) for a full walkthrough.

## Updates

ROMie checks for updates automatically and will let you know when a new version is available. You can install it without losing any of your library data or settings.
